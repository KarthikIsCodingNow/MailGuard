Section 03 // Pipeline Blueprint

Architecture & Forensics

Detailed blueprint of the 7-stage TRACE-AI forensic detection pipeline, explaining why text-only machine learning fails on spear-phishing and how multi-source fusion solves it.
01

MIME Parsing & Extraction

Decodes multi-part RFC-822 email streams. Extracts plain text and HTML bodies, email headers, and attachments with SHA-256 cryptographic hashes.

email_parser.py // header_parser.py
02

Forensic Header Auth

Parses SPF, DKIM, and DMARC verification results to identify spoofed sender domains. Reconstructs chronological SMTP relay hops to uncover originating MTAs.

auth_analysis.py // received_chain.py
03

Domain & Threat Intelligence

Queries RDAP for domain registration age, registrar credibility, and DNS MX/A records. Flags IP-as-hostname URLs and high-risk newly registered domains.

domain_intelligence.py // ip_intelligence.py
04

Lookalike Domain Detection

Detects brand impersonation through homoglyph character substitutions (e.g. 0 → o, 1 → l), Punycode IDNs, and Levenshtein edit distance.

lookalike_detector.py
05

NLP Threat Heuristics

Deterministic linguistic analyzer detecting social engineering persuasion patterns: urgency deadlines, credential harvesting, fear of suspension, and CEO wire fraud.

nlp_analyzer.py
06

Dual Machine Learning

Combines a TF-IDF + Logistic Regression text classifier (100k features) on SpamAssassin with a Random Forest tabular classifier trained on forensic metadata.

train_text.py // predict_text.py
07

Evidence Fusion Engine

Integrates 8 independent evidence families with weighted voting (forensics 22.5%, NLP 18%, lookalike 13.5%, auth 13.5%, ML 10%) and multi-family reinforcement.

evidence_fusion.py
08

Neo4j Graph Correlation

Stores emails, domains, IPs, URLs, and attachment hashes in a graph database. Queries cross-case graph traversals to uncover coordinated phishing campaigns.

neo4j_client.py // correlation.py

Axiom: Why Spam Detection is Not Phishing Detection

01. Semantic Divergence

Spam is unsolicited bulk marketing (e.g. discount loans, cheap pharmaceuticals). Phishing is targeted impersonation and credential theft. The vocabulary of sophisticated spear-phishing is virtually indistinguishable from legitimate business mail.

02. The Single-Sentence Trap

A spear-phishing email can read simply: "Hi John, please review the attached corporate invoice." Pure text machine learning will classify this as 100% Benign (HAM). Only header inspection (SPF fail) and attachment analysis will catch it.

03. Multi-Source Redundancy

By treating text ML as only 10% of the final score and requiring independent corroboration from Authentication, Forensics, and Lookalike Intelligence, TRACE-AI eliminates single-point-of-failure vulnerabilities.
